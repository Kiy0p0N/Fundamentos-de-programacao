## Fundamentos de programação

A disciplina fundamentos de programação tem como objetivo introduzir os conceitos básicos de lógica de programação e desenvolvimento de algoritmos, utilizando a linguagem C como ferramenta principal.

### Objetivos
- Desenvolver o raciocínio lógico e algorítmico
- Aprender a resolver problemas de forma estruturada
- Compreender os fundamentos da programação em linguagem C
- Criar programas simples e organizados
